# Algorithm Comparator

A Python-based **Data Structures and Algorithms Comparator** developed with PyQt5. This desktop application allows users to compare different algorithms and data structure operations through an interactive graphical interface.

## Features

### 1. Array Operations
- Insertion
- Deletion
- Linear Search
- Binary Search

### 2. Sorting Algorithms
- Bubble Sort
- Selection Sort
- Insertion Sort

### 3. Linked List Operations
- Insertion
- Deletion
- Updation
- Linear Search

### 4. Stack Operations
- Push
- Pop

### 5. Queue Operations
- Enqueue
- Dequeue

### 6. Algorithm Comparison
- Compare two selected operations.
- Display time complexity.
- Track comparisons and operations.
- Visualize algorithm execution.
- Display performance-related results.

## Technologies Used

- **Programming Language:** Python
- **GUI Framework:** PyQt5
- **Numerical Operations:** NumPy
- **Visualization:** Matplotlib
- **UI Design:** Qt Designer
- **Design Prototype:** Adobe XD

## Requirements

Install the required Python libraries:

```bash
pip install PyQt5 numpy matplotlib
```

## How to Run

1. Install Python on your system.
2. Install the required libraries.
3. Clone this repository:

```bash
git clone https://github.com/areeshamanzoor450/Algorithm-Comparator.git
```

4. Open the project directory:

```bash
cd Algorithm-Comparator
```

5. Run the application:

```bash
python main.py
```

## Purpose

This project was developed as a Data Structures and Algorithms academic project to demonstrate algorithm operations, compare their behavior, understand time complexity, and visualize execution through a graphical interface.
